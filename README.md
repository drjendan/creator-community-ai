# Creator Community AI

Three-day MVP starter for a multi-tenant, white-label community platform.

## Included in this starter

- Next.js App Router
- TypeScript strict mode
- Tailwind CSS
- Supabase browser and server clients
- Initial multi-tenant schema
- Initial Row-Level Security policies
- Premium landing-page shell
- Environment-variable template
- Three-day implementation plan

## Local setup

1. Install Node.js 20 or later.
2. Copy `.env.example` to `.env.local`.
3. Add your Supabase project URL and anonymous key.
4. Run the SQL migration in Supabase.
5. Install dependencies with `npm install`.
6. Start the app with `npm run dev`.
