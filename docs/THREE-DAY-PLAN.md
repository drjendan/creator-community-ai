# Three-Day MVP Plan

## Day 1: Foundation
- Supabase project and environment variables
- Authentication
- Tenant-aware routing
- Roles and permissions
- Branding variables
- Seed tenant and demo accounts
- Public and member shells

## Day 2: Core modules
- Podcast CRUD and episode pages
- Course/module/lesson CRUD
- Resource library
- Events and RSVP
- Community posts and comments
- Tenant admin forms

## Day 3: AI and launch
- Provider adapter for OpenAI, Anthropic, and Gemini
- Encrypted tenant key storage
- Knowledge retrieval
- AI Coach chat
- Membership-plan configuration
- Super-admin tenant management
- Responsive QA and deployment
